## 三步怎么串的

1. **音色克隆**：`POST /api/clone-records`（参考音 = `素材包\音频\新录音 17.m4a`，文本 = `口播稿.txt` 117 字）→ 上游 indextts → 27.18s mp3。
2. **克隆人**：`POST /api/compose-videos {composeType:"lipsync", seconds:27, resolution:"1080"}`（照片 = `人物参考_重截.png`，音频 = 上一步 mp3）→ 上游 musetalk → 576×1024 视频。
3. **混剪**（本次新增接口）：
   - `POST /api/timeline/sources` 上传 39 段工厂实拍 + 配音 + 数字人视频（复用缓存，秒级）；
   - `POST /api/timeline/jobs`，`clips` = 39 段、`voiceover` = 克隆音色、`person` = 数字人、`cues` = 口播稿按句切分铺时间码；
   - 轮询 `GET /api/timeline/jobs/:id`，约 28s 出片，`resultUrl = /uploads/timeline/jobs/<id>.mp4`。

## 成片参数

| 项 | 值 |
|---|---|
| 分辨率/帧率 | 720×1280 / 25fps |
| 画面 | 实拍铺满 + 轻微调色（contrast 1.05 / saturation 1.07 / unsharp 0.3） |
| 画中画 | 直径 240、位于 (240,70)，圆形遮罩 + 白环，源自数字人视频人脸区域 |
| 字幕 | 微软雅黑 60px 粗体、白字黑描边、关键词黄、`MarginV`=175，按标点断句（12 条） |
| 音频 | 克隆音色，`loudnorm -15 LUFS` → mean −16.1dB / max −1.5dB |
| 镜头 | 12 个，选片去重 + 不连用同一支素材 |

- **字幕时间码不是从音频对齐的**：软件没有 ASR（`packages/server/prisma/skills-content.ts:923`），cues 是按字数比例铺的，口播换文本后要重算。

- 服务端串行渲染（并发 1）。
- 桌面端 UI 还没接这个接口，目前走 HTTP。
