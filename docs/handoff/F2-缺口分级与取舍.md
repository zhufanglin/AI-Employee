# T-40 F2 缺口分级与取舍

审计基线：docs/fidelity-matrix.md 与 scripts/audit/out/diff.json；静态快照，不是当前运行验收。原版 237 路由与 147 IPC，分别精确缺 94 与 135；47 表缺 13。字段名另有 159 项缺失（其中共有表 7 项），本任务不将其误算为表缺口。静态结果可能漏报动态注册、存在替代实现或已过时；逐项分级是排查建议，不是已证实的故障、兼容性或验收结果。

A = 可能影响体验版核心链路，优先实证；B = 体验、运维或范围待定，后续评估；C = 有历史范围依据，体验版暂缓，非永久删除。A级不意味着必须复制同名接口；但完整 F2 兼容目标仍须独立验收，替代实现不能自动算命中。体验版团队、管理员手工开通、个人微信、云媒体等以用户最新决定为准；旧文档有相互冲突的历史判断，以下建议不代替用户决策。

人日均为**单项排查及最小适配粗估**（0.5 人日粒度，不含复杂平台联调、迁移、真实验收或未知风险），并行相关项共享工作，不可逐行相加得到排期；C 的 0.5 是恢复前评估成本，不是已批准开发量。
