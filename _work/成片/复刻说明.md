## 复现命令
```powershell
$sb=[scriptblock]::Create([IO.File]::ReadAllText((Resolve-Path '_work\build-base.ps1'))); & $sb   # 切镜头 → _work\edit\base.mp4
# 合成（底片 + 圆头画中画 + ASS 字幕 + 调色 + 淡入淡出 + 响度）
cd _work\edit
$sub = "subtitles=filename='C\:/Users/30290/Desktop/fcmediaagent-replica/_work/cap.ass':fontsdir='C\:/Windows/Fonts'"
$fc = "[0:v]trim=0:58.69,setpts=PTS-STARTPTS,eq=contrast=1.05:saturation=1.07,unsharp=5:5:0.35[bg];[1:v]crop=320:320:0:128,scale=240:240,format=rgba[pc];[pc][2:v]alphamerge[pip];[bg][pip]overlay=240:70[v1];[v1][3:v]overlay=240:70[v2];[v2]$sub,fade=t=in:st=0:d=0.35,fade=t=out:st=58.15:d=0.55,format=yuv420p[vout];[4:a]afade=t=in:st=0:d=0.15,afade=t=out:st=58.2:d=0.45,loudnorm=I=-15:TP=-1.5:LRA=11[aout]"
ffmpeg -y -i base.mp4 -i dh.mp4 -loop 1 -i mask.png -loop 1 -i ring.png -i vo.m4a -filter_complex $fc -map "[vout]" -map "[aout]" -t 58.69 -r 25 -c:v libx264 -crf 19 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart final2.mp4
```
（`dh.mp4` 为数字人口播，`mask.png`/`ring.png` 为圆形遮罩与白色描边，`vo.m4a` 为原始口播。）

## 已知限制 / 可再优化- 数字人只有 320×576（上游 resolution 上限 576，写死更大分辨率会 OOM），所以只做 240px 画中画；对标视频那种「真人全屏说话」段落，本片用画中画替代（真人口播素材对不上这段口播的嘴型）。
- 无背景音乐（素材包内没有可商用 BGM），需要的话补一条 30–40% 音量的轻鼓点卡点 B。
- 若要用软件的「智能混剪」出 AI 卡点片：见 `_work\b2-resubmit.mjs`（smart_clip appId 2096795601945350145，画幅选项必须是 `9:16 (Portrait Widescreen)` 这类上游 select 名，传 `9:16` 会被上游 KeyError 拒掉）。

## B 线：软件「智能混剪」AI 卡点片（15s）
- 入口：桌面端「智能混剪」→ `POST /api/compose-videos {composeType:"mixcut"}` → 服务端转 `POST /api/media/apps/smart_clip/broadcast_mixcut`（RunningHub appId 2096795601945350145）。
- 入参：参考人像 `人物\runninghub-first-frame.png` + 提示词（15 个分镜、精密模具与注塑一体化工厂、主标题「精密模塑 一体化」）+ 时长 15 + 画幅 `9:16 (Portrait Widescreen)` + megapixels 0.9。
- 结果：15.08s / 736×1280 / 24fps / 8.5MB，AI 生成电影感镜头 + 人物 + 中英字幕（PRECISION MOULDING / SOLUTION），约 13 分钟出片。
- 踩坑：画幅传 `9:16 (Portrait)` 会报 `KeyError: '9:16 (Portrait)'`（上游 ComfyUI ResolutionSelector 只认固定 select 名，如 `16:9 (Widescreen)`、`9:16 (Portrait Widescreen)`），任务失败但自动退款。
- 与 A 线的差别：智能混剪是「一张人像 + 一段提示词」纯 AI 生成，**不吃你的实拍素材和口播**；要把 40 段工厂实拍 + 58.7s 真人口播剪成对标片，仍得走 A 线。
