# 客户聊天成交分析官｜新手使用说明

技术名称：`boss-chat-deal-analyzer`

## 这个Skill有什么用

它专门分析单个客户的聊天记录，判断客户说“考虑一下”“价格有点高”“回头联系”背后可能是什么顾虑，并给出风险更低的下一句回复。

## 使用前准备

- 按时间顺序整理销售和客户的聊天。
- 说明销售卖什么、价格是多少。
- 如已知，请补充客户身份和当前阶段。

可参考总文件夹中的 `聊天记录示例.txt`。

## 新手怎么使用

> 使用 $boss-chat-deal-analyzer，分析下面这段聊天。请把事实和推测分开，判断客户最大的真实顾虑，并给我下一句怎么回。

客户给出新回复后，可以继续说：

> 客户刚刚这样回复，请继续使用 $boss-chat-deal-analyzer 更新判断和下一句话。

## 你会得到什么

- 一句话成交判断。
- 需求、预算、决策权、时间和顾虑证据表。
- 首选回复及不同情况下的备用回复。
- 销售做得好的地方和最需要改进的一点。

## 是否需要CLI

不需要CLI，直接粘贴聊天或上传TXT、PDF、DOCX均可。

## 使用提醒

它不会读心。所有心理判断都会标注置信度，并引用客户原话作为依据。发送建议前请确认真实产品能力和优惠边界。
