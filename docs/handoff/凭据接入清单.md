## 三、重要发现：原版把密钥加密存在数据库里

- 实现：`dist/common/services/crypto.service.js` —— `aes-256-cbc`，密钥 `scryptSync(ENCRYPTION_KEY, "salt", 32)`，密文格式 `ivHex(32) + ":" + cipherHex`。
- `ENCRYPTION_KEY` 在**生产服务器** `/www/wwwroot/fcmediaagent.com/server/.env`（34 字符）。
- 复刻的做法：**不在数据库里存密钥**，统一走 `.env` + `packages/server/secrets/`（已加 .gitignore，永不入库）。
- 脚本：`scripts/import-secrets.mjs`（读 `_extract/config-dump/*.tsv` → 解密 → 写 .env 与 PEM；输出只打掩码）。用法：
  ```
  $env:FCM_ENC_KEY = "<生产 .env 的 ENCRYPTION_KEY>"
  node scripts/import-secrets.mjs
  ```

## 四、网络注意事项

- 阿里云 `dysmsapi.aliyuncs.com` 必须 **POST + RPC 签名**（GET 返回 `UnsupportedHTTPMethod`）；Node 侧要 `--dns-result-order=ipv4first`，否则偶发 `UND_ERR_CONNECT_TIMEOUT`（IPv6 优先导致）。
- 生产机 8.163.59.118 上的密钥属于线上，**不要**把复刻服务连到生产库；复制密钥是允许的，共用库不允许。
