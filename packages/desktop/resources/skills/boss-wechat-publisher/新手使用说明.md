# 公众号自动运营发布官｜新手使用说明

技术名称：`boss-wechat-publisher`

## 这个Skill有什么用

它可以把老板观点、录音转写或文档整理成公众号文章，生成标题、摘要、正文、HTML排版、封面建议和发布检查表；客户完成公众号授权后，还可以创建草稿并提交发布。

## 使用前准备

- 文章主题、目标读者和希望达到的目的。
- 老板原始观点、案例、数据和图片。
- 希望读者看完后采取的唯一动作。

需要自动发布时，客户自行准备公众号AppID、AppSecret、IP白名单、接口权限和封面`thumb_media_id`。密钥不要发到聊天里。

## 新手怎么使用

只写文章时输入：

> 使用 $boss-wechat-publisher，把这份素材整理成一篇1500字公众号文章，先给标题和结构，我确认后再写正文。

准备发布时输入：

> 使用 $boss-wechat-publisher，检查公众号CLI配置，生成article.json和发布包，先创建草稿，不要直接发布。

## 你会得到什么

- 标题10个、摘要3个。
- Markdown正文和公众号HTML正文。
- 封面文案、视觉说明和配图位置。
- `article.json`和发布前检查表。
- 授权后返回草稿media_id或发布publish_id。

## CLI怎么确认

查看本文件夹 `references/cli-setup.md`，然后运行：

```bash
python scripts/wechat_cli.py check
```

创建草稿和发布分别需要`DRAFT`、`PUBLISH`确认词，防止误操作。

## 使用提醒

创建草稿成功不等于已经发布，提交发布也不等于公众立即可见。发布前必须人工检查事实、图片版权、错别字和移动端预览。
