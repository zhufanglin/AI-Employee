## 发布新版本
1. 改 `packages/desktop/package.json` 的 `version`（必须比线上大，如 0.1.1）。
2. 打包：`cd packages/desktop && node ..\..\node_modules\electron-builder --win nsis`（先清掉占用 release 目录的残留进程）。
3. 发布：`node scripts/publish-update.mjs`（自动 scp latest.yml + exe 到服务器并校验 200/206）。

## 坑
- **产物名必须 ASCII**：`electron-builder.yml` 已改为 `artifactName: fcmediaagent-ai-employee-${version}-${os}-${arch}.${ext}`。
  早期产物名是中文「中科元晟 AI员工-0.1.0-win-x64.exe」，URL 需要百分号转义，nginx 在非 UTF-8 locale 下有 404 风险；
  `scripts/publish-update.mjs` 现在会直接拒绝含非 ASCII 字符的产物名。
- `latest.yml` 用 PowerShell `Set-Content -Encoding utf8` 写入会带 BOM（PowerShell 5.1），Node 侧 `readFileSync` 后要 `replace(/^\uFEFF/,'')` 再解析，否则 `^version:` 匹配不到。
- 安装包 127MB，scp 到美国节点约 1–2 分钟，务必后台跑。
- 安全组需放行 80/443（已有 ai/api 站点，说明已放行）。
- 更新下载目录不是公开桶：走 nginx 静态文件，无鉴权，靠「文件名不可猜 + 无目录列表（autoindex off）」保护。
