## 2. 三个根因（这一轮的主要产出）

### 2.1 页面脚本语法错误（决定性根因）
- 现象：`waitUploadDone` 里每轮 `executeJavaScript(UPLOAD_STATE_SCRIPT)` 都精确卡 20 秒（= `EVAL_TIMEOUT_MS`）后返回 null，但同一个窗口执行 `(() => "ping")()` 秒回；外部 CDP 探测页面 `{"ms":3-8,"roots":2,"vids":5}` 完全正常。
- 根因：`packages/desktop/src/main/platform.ts` 里 `UPLOAD_STATE_SCRIPT` 用**单引号拼接**写页面脚本，其中 `editorMarks` 含 `["input[placeholder*=\"标题\"]"]` 这样的转义引号，经过拼接后转义丢失，编译产物里变成 `["input[placeholder*="标题"]"]`（引号未转义）⇒ 浏览器解析时 **SyntaxError** ⇒ `executeJavaScript` reject ⇒ 返回值恒 null（表现为"挂死 20 秒"）。
- 修法：把该段候选选择器换成不含转义引号的形式（统一用双引号数组）。
- **排障方法（可复用）**：把编译产物 `packages/desktop/out/main/index.js` 中的脚本字面量抽出来做语法校验：
  1. `_probe/extract2.cjs` 手工解析单引号字面量（处理 `\\n`/`\\t` 反转义）写出 `_probe/page-script.js`；
  2. `node --check _probe/page-script.js`，退出码非 0 就是页面侧语法错误。
- **连带教训**：`electron-vite build` 失败时只在 stderr 打 `✗ Build failed`，stdout 尾部仍像成功，`out/main/index.js` 保持旧内容（字节数不变是信号）。诊断代码里用 `''`（空单引号）会直接让 esbuild 报错并静默 build 失败。

### 2.2 发表按钮在 shadow DOM
- 视频号发表页整页在 `<wujie-app>` 的 shadowRoot 内，普通 `document.querySelectorAll('button')` 找不到「发表」。
- 新增 `SUBMIT_TARGET_SHADOW_SCRIPT`：广度收集 document + 各层 shadowRoot（上限 60）→ 收集候选（`button, [role=button], .weui-desktop-btn, a[class*=btn], div[class*=btn]`）→ 可见性过滤（rect > 0 + getComputedStyle）→ 文本命中 `发表/发布`（去空白比较）→ 优先 primary → 返回中心坐标供真实鼠标点击。
- `clickSubmit` 先试 shadow 版，未命中再退回旧的 `SUBMIT_TARGET_SCRIPT`，并打印 `[click] shadow 版未命中 {...}` 便于定位。

### 2.3 成功判定缺 URL 维度
- 视频号点「发表」后**直接跳 `/platform/post/list`**，页面上没有「发表成功」字样，只靠 `successHint` 会一路判失败到 120 秒超时。
- 修法：`packages/desktop/src/main/platform-drivers.ts` 的 `PlatformDriver` 增加可选 `successUrlHints?: string[]`；`shipinhao` 配 `['/platform/post/list']`；`platform.ts:waitPublishOutcome` 优先用 driver 自己的 `successUrlHints`，缺省仍是 `['/content/manage','publish-success']`。
