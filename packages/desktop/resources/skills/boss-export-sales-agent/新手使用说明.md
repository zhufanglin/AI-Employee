# AI外贸开发客户员工｜新手使用说明

技术名称：`boss-export-sales-agent`

## 这个Skill有什么用

它帮助工厂和外贸企业选择海外市场、定义理想买家、寻找或筛选海外企业客户，并生成英文邮件、LinkedIn和WhatsApp开发内容。

## 使用前准备

- 产品英文名称、核心卖点和价格带。
- 目标国家、客户类型和采购角色。
- MOQ、认证、产能、交期等真实资料。
- 不能承诺的内容和主要交易风险。

## 新手怎么使用

> 使用 $boss-export-sales-agent，我们生产商用咖啡机，想开发东南亚经销商。先帮我比较3个国家，再生成首批客户画像和英文开发信。

已有名单时：

> 使用 $boss-export-sales-agent，分析这份海外企业名单，筛出最可能成为经销商的20家并写触达理由。

## 你会得到什么

- 优先国家和市场风险。
- 海外客户名单、匹配分及公开证据。
- 邮件、LinkedIn、WhatsApp开发序列。
- 每条英文内容的中文释义。

## 是否需要CLI

市场研究和内容生成不强制CLI。自动查询Apollo、LinkedIn、海关数据或CRM时，由客户自行登录和配置。任何付费查询或批量发送都必须先确认。

## 使用提醒

不要填写虚假认证、客户案例或产能。不同国家的隐私、反垃圾邮件、出口和清关要求需要客户或专业人员复核。
