# T-30 媒体编排（compose-videos / clone-records / audio-materials）

> 完成时间：2026-11-05（dsh-lead 接手 codex 的 blocked 产物后重写编排层）
> 契约来源：原版 `_extract/server1027/dist/{compose-videos,clone-records,audio-materials}`

## 1. 结论

三层编排已按原版契约补齐，并且**真正接到媒体服务**（不再是空壳 CRUD）：

| 模块 | 路由 | 行为 |
|---|---|---|
| compose-videos | `POST /`、`GET /`、`PATCH /:id`、`DELETE /:id`、`POST /:id/transfer-oss`、`POST /musetalk-callback` | lipsync/realman_mix 提交代 media 的 lipsync 工作流；mixcut/news 提交 smart_clip；列表时按上游状态推进状态机 |
| clone-records | `POST /`、`GET /`、`PATCH /:id`、`DELETE /:id` | 提交 indextts 克隆任务，列表时轮询上游结果 |
| audio-materials | `POST /upload`、`GET /`、`DELETE /:id` | 支持直接给 audioUrl，或给 `{fileName,mime,base64}` 由媒体服务上传后入库 |

三张表沿用原版的 `phone` 归属键；`packages/server/src/common/owner.ts` 的 `resolvePhone()` 负责从 JWT 用户取 phone，缺失时回查 User（邮箱登录用户会得到明确的「未绑定手机号」错误）。

## 2. 状态机（与原版一致）

```
lipsync / realman_mix : cloning_audio → composing → completed | failed
mixcut  / news        : composing              → completed | failed
clone-record          : polling                → completed | failed
```

- 初始状态在 `create` 时按 composeType 落库（`mixcut|news → composing`，其余 `cloning_audio`）。
- `GET /compose-videos` 每次最多推进 **5 条**未完成任务（`REFRESH_LIMIT`），避免拖慢列表；推进逻辑是 `refresh()`：查 media 任务 → SUCCESS→completed、FAILED/ERROR→failed、其余且当前为 cloning_audio→composing，并回写 `resultUrl`。
- `musetalk-callback` 按 `musetalkTaskId` / `smartClipTaskId` 幂等匹配，未知 taskId 返回 404。

## 3. 计费

编排层**不重复计费**，全部复用 `packages/server/src/media/media.service.ts`：

- `submit()` 先按 MediaPricing 预扣（`consumeCreditsWithPartial`），提交失败自动 `addCredits(refund)`。
- 媒体任务不吃免费额度，余额不足返回 402「算力不足，请充值」。
- 冒烟实测：两种「上游未配置/素材非法」的失败提交后，账号积分**原样退回**。

真实单价（seed 占位价，需用户定价后改）：lipsync 1.2 积分/秒、smart_clip 0.5/秒、indextts 10/次。

## 4. 桌面端

`packages/desktop/src/renderer/src/pages/MediaStudio.tsx`（真实实现，替换 codex 的占位页）：

- 「数字人」：选人像图片 + 口播音频 → 都经 `/media/files/upload` 上传到上游素材库 → `POST /compose-videos` → 8 秒轮询列表显示状态与成片链接 → 可「转存」（`POST /:id/transfer-oss`）。
- 「音色克隆」：上传音频 → `POST /clone-records` → 轮询克隆结果；下方同时列出音频素材库（删除）。
- IPC：`packages/desktop/src/main/index.ts` 新增 `media:upload|compose-*|clone-*|audio-*`；`packages/desktop/src/preload/index.ts` 暴露 `window.fcm.media.{upload,compose,clone,audio}`。

## 5. 上游依赖（部署前必须配）

| env | 用途 | 现状 |
|---|---|---|
| `RUNNINGHUB_API_ID` | lipsync 工作流（默认 2031016553440878594） | 已配置 |
| `RUNNINGHUB_API_ID_INDEXTTS` | 音色克隆工作流 | **未配置** → 提交返回 400 |
| `RUNNINGHUB_API_ID_SMART_CLIP` | 智能混剪工作流 | **未配置** → 提交返回 400 |

未配置时行为是「明确报错 + 积分退回」，不会静默吞掉。补齐这两个 API ID 后混剪/克隆即可真实出片。
