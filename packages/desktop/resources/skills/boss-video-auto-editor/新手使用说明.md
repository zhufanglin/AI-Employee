# AI短视频自动剪辑师｜新手使用说明

技术名称：`boss-video-auto-editor`

## 这个Skill有什么用

它可以处理客户提供的本地视频，检查素材、转写口播、设计删减点、识别高价值片段、生成字幕，并把长视频拆成多条横版或竖版短视频。

## 使用前准备

- 实际视频文件，例如MP4、MOV或MKV。
- 期望拆成几条、每条多长、发布到哪个平台。
- 客户电脑需要自行安装FFmpeg和ffprobe。
- 建议安装Whisper；需要自动删静音时可安装auto-editor。

详细配置位于本文件夹 `references/cli-setup.md`。

## 新手怎么使用

先把视频放进工作区，再输入：

> 使用 $boss-video-auto-editor，检查这个视频，先给我5条拆分方案和每条的起止时间，不要立即渲染。

确认方案后再说：

> 我确认这5条方案，请使用 $boss-video-auto-editor 输出1080×1920竖版成片，原视频不能覆盖。

## 你会得到什么

- 视频时长和画面参数检查。
- 每条短视频的标题、起止时间和保留理由。
- `segments.json`剪辑清单。
- 配置成功后生成的MP4成片和渲染清单。
- 标题、封面和平台发布建议。

## CLI怎么确认

在终端运行：

```bash
python scripts/video_cli.py check
```

只有显示`ready_for_render: true`时才能真实渲染。客户负责安装CLI，Skill负责调用和检查结果。

## 使用提醒

没有真实生成并检查文件时，Skill不能说“已经剪好”。它不会覆盖或删除原素材；自动删停顿可能误伤语义，成片必须抽查。
