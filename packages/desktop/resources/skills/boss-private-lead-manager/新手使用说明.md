# 私域客户分层跟进官｜新手使用说明

技术名称：`boss-private-lead-manager`

## 这个Skill有什么用

它可以整理微信私域或CRM客户表，去重并分成S/A/B/C/D层，告诉你今天必须跟谁、为什么跟、说什么，以及哪些客户应该降低频率或停止联系。

## 使用前准备

按总文件夹的 `私域客户导入模板.csv` 准备资料，重点包含：

- 客户名称、来源和最后联系时间。
- 需求、预算、决策角色和主要顾虑。
- 当前负责人和下一步日期。

## 新手怎么使用

> 使用 $boss-private-lead-manager，分析这份私域客户表，分成S/A/B/C/D层，并生成今天的跟进名单和话术。

盘活沉默客户时：

> 使用 $boss-private-lead-manager，找出30天以上没联系但仍值得唤醒的客户，给出唤醒理由和消息。

## 你会得到什么

- 今日跟进看板和优先顺序。
- 每位客户的分层、得分和判断证据。
- 今天目标、建议话术、负责人和下次日期。
- 需要老板介入、暂停联系或转客服的客户。

## 是否需要CLI

上传CSV/XLSX不需要CLI。需要自动读取或写回企业微信、CRM时由客户自行配置；写回标签和发送消息前必须确认。

## 使用提醒

不要把完整身份证、银行卡等无关敏感数据交给Skill。明确拒绝、投诉和退订客户必须停止营销。
