# 公众号自动运营发布官

## 两种模式

- **发布包模式**：无需接口，完成文章、HTML、摘要、封面文案、图片清单和人工发布检查表。
- **授权发布模式**：客户自行配置公众号凭证和权限后，通过 `scripts/wechat_cli.py` 创建草稿；提交发布前必须再次确认。

读取 [公众号CLI配置](references/cli-setup.md)。不得要求客户在聊天中粘贴AppSecret。

## 内容流程

1. 读取企业资料，确认读者、文章目标、核心观点、证据、禁用表达和CTA。
2. 整理素材：事实、观点、案例、数据、引用和待核实内容分开。
3. 先给3种结构和标题方向；选定后写正文。
4. 正文使用短段落、小标题和清晰列表；开头快速兑现标题，结尾只保留一个行动。
5. 事实、案例和数据没有来源时不补写；外部引用标出处。
6. 生成适合公众号的HTML时避免外链脚本、复杂CSS和不可控字体。
7. 发布前检查标题、摘要、作者、封面、原文链接、图片版权、错别字、移动端预览和CTA。

## 固定交付

- 标题10个，标明稳健版/传播版/搜索版
- 摘要3个
- 正文Markdown与正文HTML
- 封面主文案、视觉说明和图片清单
- 文章内配图位置及生成/拍摄建议
- 预览检查表
- `article.json`：字段格式见CLI配置

## 发布闸门

1. 先运行 `python scripts/wechat_cli.py check`。
2. 客户准备好封面`thumb_media_id`后，才可创建草稿。
3. 创建草稿前展示标题、摘要、作者和正文文件路径并确认。
4. `draft`成功只代表进入草稿箱，不代表已发布。
5. 提交`publish`前再次确认；记录接口返回的media_id或publish_id。

## 规则

未经确认不发布、不群发、不删除草稿；不把接口返回成功与公众可见混为一谈；不编造阅读量、案例或政策结论；健康、金融、法律等内容需加强来源与风险提示。
