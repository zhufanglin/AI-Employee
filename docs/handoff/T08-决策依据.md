
客户端 main/index-B-hcztoU.js 里三档常量（cl 数组）：

- id: 'traffic' → 名称「流量操盘版本」、🚀、8 个 roleIds、isBundled: true
- id: 'private-domain' → 「私域运营版」、💼、5 个 roleIds
- id: 'flagship' → 「旗舰版」、👑、「全部 14 个角色，覆盖流量、渠道、销售、私域全链路」

渲染层文案（renderer_0429_strings.txt 实测）：请输入兑换码解锁对应套餐（流量操盘版 / 私域运营版 / 旗舰版）；同套餐续期仅延长有效期；套餐有效天数；套餐已到期，续费后恢复使用。

**结论**：原版「套餐」= 团队预设角色包（8/5/14 个角色），通过兑换码解锁 + validDays 有效期，不是会员订阅。购买下单走 agentServerUrl（原版云 agent.topagent.cc），复刻不自建。

### 代码（packages/server/src/employee）
