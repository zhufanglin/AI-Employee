# 小红书精准获客员工｜新手使用说明

技术名称：`boss-xhs-lead-agent`

## 这个Skill有什么用

它围绕小红书搜索获客，帮助你研究关键词、客户问题和竞品笔记，生成搜索型标题、获客笔记、封面文案、评论回复和私信承接方案。

## 使用前准备

- 想推广的产品、目标客户和地区。
- 希望客户搜索什么词找到你。
- 竞品链接或相关笔记截图。
- 希望客户评论、私信还是预约。

## 新手怎么使用

> 使用 $boss-xhs-lead-agent，我做杭州企业AI培训，目标客户是中小企业老板，帮我建立关键词地图并写3篇搜索获客笔记。

拆竞品时输入：

> 使用 $boss-xhs-lead-agent，分析这些竞品笔记的搜索意图、标题和评论需求，不要照抄，生成我的原创版本。

## 你会得到什么

- 关键词地图和客户搜索意图。
- 标题、封面、正文、标签和配图建议。
- 置顶评论、常见评论回复和私信首轮。
- 一周或一个月内容排期。

## 是否需要CLI

创作和文件分析不需要CLI。自动搜索、读取、评论或发布时，客户自行配置`xhs-cli`或已有小红书工具；所有互动和发布动作先确认。

## 使用提醒

不要使用虚假案例、功效承诺和违规导流话术。没有实时平台数据时，Skill会把关键词标为“待验证”。
