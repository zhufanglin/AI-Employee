用户侧：
- `GET  /api/payments/wechat/status`（公开）→ 支付是否已配置（未配置时前端应隐藏购买入口）
- `POST /api/payments/orders` `{packageId}` → `{orderNo, codeUrl, amount, credits, expiredAt}`
- `GET  /api/payments/orders/mine?page=&limit=`
- `GET  /api/payments/orders/:orderNo`

管理侧（`@Roles("admin")`，Bearer JWT 来自 `POST /api/auth/admin/login`）：
- `GET  /api/admin/overview`

- `GET  /api/admin/orders?status=&keyword=`（订单号/手机号/微信交易号）

- `GET  /api/admin/users?keyword=`
- `POST /api/admin/users/:id/credits` `{amount, reason}`（正数 gift，负数 consume）
- `GET  /api/admin/credit-transactions?userId=&page=`

## 3. 关键机制

1. **金额单位**：数据库 `Order.amount` / `CreditPackage.price` 均为**分**（原版 `packages.service.js` 即 `Math.round(price*100)`）。微信 V3 `amount.total = order.amount`，无需换算。
2. **幂等入账**：`markPaid` 事务内 `updateMany({where:{id,status:"pending"}})` 抢占，`count===0` 直接返回 `{alreadyPaid:true, credited:0}`，重复回调不会重复加积分。
3. **金额校验必须在事务外**（踩过的坑）：事务内改状态再抛异常会整体回滚，冻结状态不落库。现为事务外预检 → 不符则单独 update `status="amount_mismatch"` → 抛 400「支付金额与订单金额不一致，已冻结订单并标记待人工核对」。
4. **回调验签**：`main.ts` 在 `setGlobalPrefix` 前 `app.use("/api/payments/wechat/notify", raw({type:"*/*"}))`，controller 取 `req.rawBody`。验签串 `timestamp\nnonce\nrawBody\n`，**时间戳超 5 分钟拒绝**（防重放）。解密：AES-256-GCM，key=APIv3 密钥，`associated_data` 作 AAD，密文末 16 字节为 authTag。
5. **过期订单**：`expireStale()` 惰性把 `pending` 且 `expiredAt < now` 改 `expired`；下单时 `expiredAt = now + 30min`。
6. **mock 链路**：`WECHAT_PAY_MOCK=1` 时 `createNativeOrder` 返回 `weixin://wxpay/bizpayurl?pr=MOCK<orderNo>`，`parseNotify` 跳过验签解密直接读明文 JSON，供本地端到端联调。verify.ps1 的 server restart 步骤只对该子进程注入此变量。
7. **管理后台套餐价格**：入参元、存储分；`priceDisplay` 自动生成 `¥x.xx`。

| 项 | 位置 | 写入 env |
|---|---|---|
| 商户号 | 已有 `1118595998` | `WECHAT_PAY_MCH_ID` |
| AppID | 已有 `wx219da5e18416b3fd`（需与商户号完成绑定） | `WECHAT_PAY_APP_ID` |
| APIv3 密钥 | 商户平台 → 账户中心 → API 安全 → 设置 APIv3 密钥（32 位） | `WECHAT_PAY_API_V3_KEY` |
| 商户 API 证书 | 账户中心 → API 安全 → 申请商户 API 证书 → 得到 `apiclient_key.pem` + 证书序列号 | `WECHAT_PAY_PRIVATE_KEY_PATH`、`WECHAT_PAY_SERIAL_NO` |
| 平台证书/公钥 | 账户中心 → API 安全 → 平台证书（或"微信支付公钥"） | `WECHAT_PAY_PLATFORM_CERT_PATH` 或 `WECHAT_PAY_PLATFORM_PUBLIC_KEY` |
| 支付回调 URL | 必须 **HTTPS 公网可达**，如 `https://api.fcmediaagent.com/api/payments/wechat/notify` | `WECHAT_PAY_NOTIFY_URL` |
| Native 支付 | 产品中心 → 开通「Native 支付」 | — |
| 商户 API 域名/授权 | 若用服务商模式另配 | `WECHAT_PAY_BASE_URL` 默认 `https://api.mch.weixin.qq.com` |

**未配置时的行为**：`GET /api/payments/wechat/status` 返回未就绪；下单返回 503 `WECHAT_PAY_NOT_CONFIGURED`。前端应据此隐藏购买按钮，避免用户点进死路。
