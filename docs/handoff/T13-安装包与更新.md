# T-13 安装包与自动更新（NSIS + electron-updater + 首启引导）

> 状态：**已完成，安装包已产出并实测安装 + 启动**（2026-11-05，dsh-lead 接手 codex 的 blocked(env)）
> 作用域：`packages/desktop/electron-builder.yml`、`packages/desktop/src/main/update.ts`、`packages/desktop/src/renderer/src/pages/Onboarding.tsx`、`scripts/release-desktop.ps1`

## 1. 之前为什么 blocked

`electron-builder` 首次构建要去 GitHub Releases 拉三个二进制包（`7zip-win-x64`、`nsis-3.0.4.1`、`nsis-resources`），国内直连 600s 超时，codex 因此标 `blocked(env)`。

**解法**（实测有效）：构建前注入镜像环境变量

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
```

首次构建后二进制缓存在 `%LOCALAPPDATA%\electron-builder\Cache`（含 `7zip@1.0.0`、`nsis-3.0.4.1`、`nsis-resources-3.4.1`），之后离线可复用。

## 3. 关键配置说明

- **版本号来源**：`packages/desktop/package.json` 的 `version`，决定安装包文件名与 `latest.yml` 的 version。发版前必须手动递增。
- **应用图标**：当前未设置（构建日志会提示 `default Electron icon is used`）。要换图标就把 `icon.ico`（256×256 多尺寸）放进 `packages/desktop/build/`，electron-builder 自动使用。
- **签名**：`win.signAndEditExecutable: false`（用户已决定代码签名证书后补）。**副作用**：exe 资源（图标/版本信息）也不会被编辑；拿到证书后改为设置 `CSC_LINK`/`CSC_KEY_PASSWORD` 并去掉该字段。
- **打包内容**：`files: out/**/* + package.json`（只打构建产物），`asar: true`；生产依赖（react、electron-updater）由 electron-builder 自动收进 asar。
- **安装包体积**：openclaw 运行时约 118MB/3 万文件，压缩后安装包预计 150–200MB。解包目录约 435MB。

## 4. 发版流程（手动，暂不接 CI）

1. 改 `packages/desktop/package.json` 的 `version`。
2. `powershell scripts\release-desktop.ps1`（或手跑第 5 节两条命令）。
3. 产物在 `packages/desktop/release/`：
   - `中科元晟 AI员工-<ver>-win-x64.exe`（安装包）
   - `中科元晟 AI员工-<ver>-win-x64.exe.blockmap`（增量更新用）
   - `latest.yml`（更新清单）
4. 把这三个文件上传到 `https://updates.fcmediaagent.com/desktop/latest/`（OSS/CDN），**保持文件名不变**。
5. 已安装的客户端 15s 内自动检查到新版本 → 设置页出现"下载新版本" → 下载完成 → "重启并安装"。

> 更新源当前指向 `updates.fcmediaagent.com`，与实际域名 `fcmediaagent.com` 不同，需要用户确认（可选：改用 `https://fcmediaagent.com/updates/desktop/latest`，或新增该子域解析）。可通过环境变量 `FCM_UPDATE_URL` 覆盖，无需改代码。

- 配置从 `signAndEditExecutable: false` 改为 **`signExecutable: false`** —— 只跳过代码签名，保留图标与版本信息编辑（日志明示 `file signing skipped via signExecutable configuration`）。
- 实测 exe 元数据：`ProductName=中科元晟 AI员工`、`FileDescription=中科元晟 AI员工`、`FileVersion=0.1.0`、`ProductVersion=0.1.0.0`。`CompanyName` 当前仍是 Electron 默认的 `GitHub, Inc.`，已在 `packages/desktop/package.json` 补 `author`（`中科元晟 <support@fcmediaagent.com>`），**下次构建生效**。

静默安装实测（`installer.exe /S /D=<目录>`）：
- 可用，但**很慢**：127MB → 435MB 解压约 2–4 分钟；期间 NSIS 先解到 `%TEMP%\nsn*.tmp`，目标目录在最后阶段才出现文件，**中途看目标目录为空是正常现象**（我第一次误判为失败并 kill，退出码 -1 就是这样来的）。
- 安装完成后目录结构正确：`中科元晟 AI员工.exe` + Electron 运行时 + `resources/{app.asar, app-update.yml, openclaw, skills, context}`。
