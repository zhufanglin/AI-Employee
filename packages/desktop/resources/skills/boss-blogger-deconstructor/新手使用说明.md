# 博主账号深度拆解官｜新手使用说明

技术名称：`boss-blogger-deconstructor`

## 这个Skill有什么用

它能拆解一个博主或企业账号的定位、人设、目标用户、选题体系、爆款结构、表达风格、更新频率、引流路径和变现模式，并帮你转化成自己的原创方案。

## 使用前准备

至少提供以下一种资料：

- 博主主页链接和10条以上内容链接。
- 主页、橱窗、评论区和产品截图。
- 视频标题、文案、转写稿或平台数据表。

样本越完整，商业模式判断越可靠。

## 新手怎么使用

> 使用 $boss-blogger-deconstructor，深度拆解这个抖音博主。请分析定位、人设、选题、爆款结构、引流和变现，并生成我能原创借鉴的方案。

对比多个账号时：

> 使用 $boss-blogger-deconstructor，对比这3个同行，告诉我各自最强的流量逻辑和最难复制的部分。

## 你会得到什么

- 一句话定位、核心用户和人设证据。
- 内容支柱、选题树和代表爆款表。
- 主页、私信、直播或产品的商业链路。
- 10个原创选题和30天验证路径。

## 是否需要CLI

上传截图、链接和数据不强制CLI。自动采集平台数据时由客户自行配置相应工具；平台受限时，Skill会要求客户提供样本。

## 使用提醒

没有公开证据时，收入、团队规模和转化路径只能写“推测”。不得复制博主的完整文案、视频和独特表达。
