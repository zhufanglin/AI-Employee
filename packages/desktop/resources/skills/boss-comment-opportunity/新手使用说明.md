# 评论区商机识别官｜新手使用说明

技术名称：`boss-comment-opportunity`

## 这个Skill有什么用

它能批量分析抖音、小红书、视频号等平台评论，区分高意向咨询、普通互动、同行、投诉和垃圾信息，帮助你找到真正值得销售人员跟进的评论。

## 使用前准备

可以提供以下任意一种资料：

- 直接复制的评论文本。
- 平台导出的评论表。
- 按总文件夹 `评论导入模板.csv` 整理的文件。
- 已授权平台CLI读取的评论数据。

## 新手怎么使用

> 使用 $boss-comment-opportunity，分析这份评论表，找出A级和B级商机，并为每条生成公开回复和私信建议。

也可以直接粘贴几条评论：

> 使用 $boss-comment-opportunity，下面哪些人是真客户？请按优先级排序，不要把普通点赞当商机。

## 你会得到什么

- 评论总览和客户问题分布。
- A/B/C/D级商机清单。
- 判断依据、公开回复和私信动作。
- 投诉、质疑和平台风险提示。
- 可转化成短视频的评论选题。

## 是否需要CLI

上传评论文件不需要CLI。需要自动获取平台评论时，客户自行配置对应平台工具。任何自动回复、私信或点赞都必须先确认。

## 使用提醒

没有企业产品资料时，Skill不会替你承诺价格、适用人数或效果。它也不会凭头像和昵称就认定对方是老板。
