# 每日精准获客选题官｜新手使用说明

技术名称：`boss-daily-lead-topics`

## 这个Skill有什么用

它每天根据产品、目标客户、客户问题和销售异议，生成真正能承接业务的短视频或图文选题，减少泛流量和无效内容。

## 使用前准备

- 今天主推的产品或服务。
- 最想吸引的客户。
- 希望客户看完后采取的动作。
- 可使用的案例、现场、数据或资料钩子。

## 新手怎么使用

> 使用 $boss-daily-lead-topics，我今天主推6980元企业AI线下课，目标是20—100人企业老板，给我今天能拍的10个精准获客选题。

做周计划时输入：

> 使用 $boss-daily-lead-topics，给我排一周内容，每天2条，流量、信任和成交内容要搭配。

## 你会得到什么

- 今天优先拍摄的3条内容。
- 10个选题及目标客户、前三秒、证明素材和CTA。
- 最快能拍、最可能带咨询和最能建立信任的选题。
- 发布后需要复盘的数据。

## 是否需要CLI

不需要CLI。若客户配置了平台数据工具，Skill可以结合近期数据；没有实时数据时不会假装使用热点。

## 使用提醒

选题必须与业务相关。标题可以有冲突感，但正文必须兑现承诺，不能编造案例、热点或效果数据。
