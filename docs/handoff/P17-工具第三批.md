# P17 工具第三批：看图 / 员工派活 / 定时任务

> 上线时间 2026-11-07 22:2x（生产 47.85.46.165）· 作者 dsh-lead · 单测 61 项 + 生产验收 18 项 GREEN

## 1. 为什么做这三块

P16 之后能力层有 19 个能力（抓取/搜索/文件/文档/音视频），但仍有三类「员工自己干不了」的活：

- **看不了图**：客户发来截图、海报、Excel 截图，员工只能读到「[图片]」占位符；
- **不会分工**：一个员工干不完的活没法交给另一个员工，也没法回看别人的进度；
- **不会定时**：用户说「每天早上 9 点帮我发一条日报」，之前只能手工点。

这三块都不依赖任何外部凭证，纯代码可交付，因此作为 P17。

## 2. 新增能力（6 个）

| 能力 | 参数 | 说明 |
|---|---|---|
| `image_understand` | `source`（工作区文件名 / key / http(s) 链接）、`question`、`model` | 看图：模型走多模态 parts（`{type:image_url}`），工作区图有 OSS 公链就传 URL，否则内联 `data:<mime>;base64,` |
| `employee_dispatch` | `employeeSlug`、`input`、`title` | 给另一个员工派活，复刻 `EmployeeService.run` 的安装/付费购买校验，按 `cliRequirement` 决定 desktop / cloud 执行器 |
| `employee_task_status` | `taskId` | 查任务：状态、标题、员工、输出（截 4000 字）、产物（文本截 300 字） |
| `cron_create` | `employeeSlug`、`cronExpr`、`timezone`、`workflowKey`、`title` | 建定时器，`nextRunAt` 用与 `CronTime` 同源的算法 |
| `cron_list` | 无 | 列自己的定时器（按 nextRunAt 升序） |
| `cron_delete` | `cronId` | 删自己的定时器（**参数名是 cronId，不是 id**） |

worker 侧白名单 `packages/worker/tool-loop.mjs` 由 17 项扩到 **23 项**，INSTRUCTIONS 补了看图 / 派活 / 定时用法。

## 3. 关键契约与坑（后面复用）

- **`POST /api/capabilities/run` 出错时仍返回 HTTP 201**，错误在 body：`{success:false, data:null, error:"中文", error_code:"HttpException"}`。验收脚本必须看 `success` 字段，不能只看状态码（P17 首轮 3 条假 FAIL 就是这个原因）。
- `pickPublicAddress(addresses)` 在全部地址被拦时**抛** `BadRequestException("禁止访问内网或保留地址")`，不是返回 null —— 调用方要 try/catch。
- `resolveWorkspaceFile(userId, {key, name})` 的 key 优先：同时传 key 和 name 时走 key 分支，普通文件名会被当成越权 key 抛「无权访问该文件」。正确写法：`source.startsWith("workspace/") ? {key:source} : {name:source}`。
- `cron_list` 返回的条目字段是 **`cronId`**（不是 `id`），`cron_delete` 只认 `cronId`。
- 员工派活并发上限：同用户 `queued`/`running` 超过 5 条拒绝；不允许 `parentEmployeeSlug` 指向目标员工本身（禁自派活）。
- `image_understand` 走 `VISION_MODEL_ALIAS`（默认 `doubao-seed-2.0-lite`），上游 `doubao-seed-2.0-pro` / `lite` 实测都支持图片输入。
- 本机 VPN 把 `example.com` 解析成 `198.18.x` 假 IP，会被 SSRF 守卫拒绝；本地断言公网 URL 用 `https://1.1.1.1/pic.png` 这类字面量地址。

## 6. 还没做

- **长期记忆检索**：Prisma 里没有 memory 表，需要新建表 + 写入/召回链路，单独排期。
- **平台操作类能力**（抖音 / 小红书 / 公众号 / 企微 的取数与发布）：都需要各平台授权，凭证到位才能开工。
- 定时任务只在服务端 CRUD，`title` 因表里没有对应列不落库（原版同样只存 workflowKey）。
