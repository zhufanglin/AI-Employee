## 2. 这些价格意味着什么（成本对照，仅算术）

按 1.1 的单价换算成人民币：

| 动作 | 消耗 | 折合收入 | 现实成本量级 | 结论 |
|---|---|---|---|---|
| 一次模型对话 | 1 积分 | ¥0.00001 ~ ¥0.0001 | 方舟一次约 ¥0.001~0.01（视模型/上下文） | **卖 1 积分/次必亏** |
| 数字人对口型 60 秒 | 72 积分 | ¥0.0007 ~ ¥0.007 | 云端 API 约 ¥0.5~2（按服务商） | **亏 2~3 个数量级** |
| AI 视频生成 1 条 | 20 积分 | ¥0.0002 ~ ¥0.002 | ¥1~10 | **亏损** |
| 音色克隆 1 次 | 10 积分 | ¥0.0001 ~ ¥0.001 | ¥0.5~3 | **亏损** |

> 成本量级取公开报价区间，仅用于说明差距，**不作为定价依据**；正式定价前需要用方舟/云厂商控制台账单跑一次真实单量核算。

结论：原版这套数字是**联调占位**，不是商业定价。任何"照原版卖"的方案都会亏钱。

## 3. 需要用户拍板的三件事（缺一不可，T-14 契约收口依赖它）

1. **积分与人民币的换算率**：1 积分 = 多少元？（决定积分包怎么卖、模型按次怎么算）
2. **模型是否改成按 token 计价**：原版 `per_request = 1` 无法覆盖长上下文成本。建议改为 `per_token` 并填 `pricePerInputToken/pricePerOutputToken`（表结构与 `PricingService` 已支持，只需填数）。
3. **媒体类单价**：混剪/对口型/视频/音色/图片各自定多少积分（按"成本 × 毛利倍数 ÷ 积分单价"倒推）。

配套（可后置）：免费额度 `freeMonthlyQuota`（现 10 次/月）、首充赠送、体验版规则。

## 4. 建议的核算方法（给用户填空用）

```
1 积分定价 = P 元
单次动作积分 = ceil(该动作真实成本 / P × (1 + 目标毛利率))
```

例：若定 1 积分 = ¥0.01，对口型云端 60 秒成本 ¥1.0，目标毛利 60% → 需 160 积分。

## 5. 怎么改价（两种，都不用发版）

**A. 积分包（已有管理后台 API）**
```powershell
# 登录拿 admin JWT
POST /api/auth/admin/login {"username":"admin","password":"<ADMIN_PASSWORD>"}
# 改现价（入参单位：元）
PATCH /api/admin/packages/{id} {"price": 9.9, "credits": 1000, "priceDisplay": "¥9.90"}
```
或直接 SQL 改 `CreditPackage.price`（分）与 `priceDisplay`。

**B. 模型 / 媒体计价（数据库，一行一条）**
```sql
-- 模型改按 token
UPDATE ModelPricing SET pricingMode='per_token', pricePerInputToken=?, pricePerOutputToken=? WHERE modelId=?;
-- 媒体改单价（积分/秒 或 积分/次）
UPDATE MediaPricing SET pricePerInputSecond=? WHERE taskType='lipsync';
UPDATE MediaPricing SET pricePerRequest=? WHERE taskType='video_gen';
```

**C. seed 默认值**：`packages/server/prisma/seed.ts` 里的数字已标注 `⚠️ 占位价`，仅用于新环境初始化；改完数据库后不要重跑 `npm run prisma:seed`，否则会被覆盖回占位值（seed 用 update，会覆盖同名字段）。

## 6. 与其它任务的接口

- **T-14 F2 契约收口**：原版 `ModelPricing` 的 `per_request=1` 是契约事实（要保留字段与模式），但**取值**属于商业决策，不进契约基线。
- **T-12 支付**：`POST /api/payments/orders` 直接用 `CreditPackage.price`（分）作为微信 `amount.total`。改价后无需改代码，但**必须同步后台套餐 `priceDisplay`**，否则用户看到的价格与实际扣款不一致（原版就有这个不一致：黄金套餐 price=100 分，priceDisplay="1"）。
- **T-08 套餐**：团队套餐（traffic/private-domain/flagship）售价与有效期仍待用户拍板，与本文件的积分定价是两套体系，可独立定价。
