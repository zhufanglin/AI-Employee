## 一、抖音图文发布（根因：发文助手「检测中」时点击被静默忽略）

失败现象：前 8 步全绿，点「发布」后页面一动不动，30 秒后仍停在编辑页，无任何 toast。

排查链路（每一步都有真机证据）：
1. `text=发布` 会命中外层 div/span（textContent 同样是「发布」）⇒ 改为
   `SUBMIT_TARGET_SCRIPT`：只取可见 `<button>/[role=button]`、文本精确等于「发布/发表」、
   优先 class 含 primary、取最后一个，返回视口坐标。
2. `el.click()` 对抖音 React 按钮无效 ⇒ `mouseClickAt()` 用
   `win.webContents.sendInputEvent({ type: 'mouseMove'|'mouseDown'|'mouseUp' })`。
3. 点击诊断（`CLICK_PROBE_INSTALL_SCRIPT` / `CLICK_PROBE_READ_SCRIPT`，捕获阶段记
   pointerdown/mousedown/mouseup/click）证明事件确实送达按钮 ⇒ 不是点不中，是页面自己忽略。
4. 对照实验：外部 CDP 客户端（`_probe/dy-click.mjs`）对同一张编辑页点同一坐标 **成功**，
   并出现 toast「发布成功」+ 跳转 `/creator-micro/content/manage`。
5. **真正根因**：右侧「发文助手」在「检测中 9%~24%」时点发布会被静默丢弃；等检测跑完
   （几分钟）再点就成功。

修法（`packages/desktop/src/main/platform.ts`）：
- `PUBLISH_RESULT_TIMEOUT_MS` 30s → **120s**，`PUBLISH_RETRY_CLICK_MS = 25000`。
- `waitPublishOutcome(win, driver, retryClick?)`：轮询成功提示（`driver.successHint`）或
  href 命中 `/\/content\/manage|publish-success/i`；每 25 秒补点一次发布，
  步骤里会出现「补点发布（检测中时首次点击可能被忽略）」。

真机结果：
```
{"ok":true,"message":"发布成功：命中成功提示「发布成功」，页面地址 https://creator.douyin.com/creator-micro/content/manage?enter_from=publish"}
```
作品管理页 `作品 (421)` 可见 3 条「抖音图文自动化校准N-可忽略」。

## 二、小红书图文发布（根因：loadURL 卡死 + 编辑器就绪误判 + 封闭 shadowRoot 按钮）

1. **`webContents.loadURL()` 对小红书会卡住**：URL 已变但 document 仍是 `about:blank`，
   30 秒后报「打开页面失败：页面没有响应」；同一个窗口用 CDP `Page.navigate` 8 秒内正常出内容。
   修法：`navigate()` 里 6 秒仍未提交就 attach debugger 发
   `Page.enable` + `Page.navigate`，日志 `[navigate] loadURL 迟迟没有提交，改用 CDP Page.navigate 重新发起`。
2. **空白页误判未登录**：新增 `probeUntilReady(win)`，最多 8 轮等页面出现登录线索/二维码/文本 >120 字。
3. **「上传素材」假就绪**：旧判定用 URL 含 `/publish/publish` —— 而那就是小红书的 homeUrl，
   一进页就为真。改为编辑器专有标记：`input[placeholder*="标题"]`、`.zone-container`、
   `.ProseMirror`、`.ql-editor`、`xhs-publish-btn` 任一可见即视为已进编辑器。
4. **发布按钮是自定义元素**：真机是
   `<xhs-publish-btn is-publish="true" is-save-draft="true" submit-text="发布" save-text="暂存离开">`，
   **shadowRoot 封闭**（`el.shadowRoot === null`），`textContent` 为空 ⇒ 文本兜底会误点「定时发布」。
   修法：driver 增 `submitPoint: { x: 0.6, y: 0.5 }`（真机「发布」在元素内 x≈0.6/y≈0.5），
   `clickSubmit()` 新增分支：`submitRectScript()` 取元素矩形 → 按比例坐标做真实鼠标点击。
5. **话题联想下拉会盖住按钮**：填完正文后 `#话题` 下拉浮层需要先按 Esc 收起，新增步骤「收起联想下拉」。

真机结果：
```
{"ok":true,"message":"发布成功：命中成功提示「发布成功」，页面地址 https://creator.xiaohongshu.com/publish/success?..."}
steps: 打开创作后台 / 检查登录状态 / 切换到发布方式 / 上传素材 / 填写标题 / 填写正文 /
       定时发布 / 收起联想下拉 / 点击发布（元素点击「xhs-publish-btn[submit-text]」比例(0.6,0.5) → (682,734)）/ 等待发布结果
```
笔记管理页 `/new/note-manager` 可见「小红书图文自动化校准-可忽略　2026-11-09 19:09」。

## 四、评论管理：抖音 / 小红书 网页版没有入口

真机核实（侧边栏 + 内容管理子菜单逐项点开）：
- 抖音创作后台只有 作品发布 / 首页 / 内容管理（作品、作品合集）/ 数据中心 / 收入变现 / 创作服务；
  `/creator-micro/interaction/comment`、`/interaction/comment-manage`、`/comment/manage`、
  `/message/comment` 全部 302 或落到通知页。`/data-center/interaction` 是有效路由但内容是互动数据，不是评论管理。
- 小红书创作后台只有 发布笔记 / 首页 / 笔记管理 / Builder hub / 小工具 / Red Skill / 数据看板 /
  活动中心 / 灵感 / 学院 / 百科；`/new/interaction`、`/new/comment`、`/comment/note`、`/new/comment-manage` 全部 404。

处理：driver 增 `commentsSupported?: boolean`，抖音/小红书置 `false`；
`comments()` / `replyComment()` 直接返回中文说明「创作后台网页版没有「评论管理」入口（2026-11-09 真机核实），暂不支持」，
不再拿失效 URL 去空白页扫 0 条（旧行为会被误解成「没登录」或「没有评论」）。
视频号保留原配置，等账号重新扫码后验证。

## 五、可复用脚本（`_probe/`，临时目录，收尾需清理）

| 脚本 | 用途 |
| --- | --- |
| `patch-asar.cjs` | 把 `out/main/index.js` 打进已安装 asar，免整包重装做真机迭代 |
| `cdp.mjs <expr>` | 在渲染层执行表达式（`window.fcm.platform.*`），Node 24 自带 WebSocket |
| `cdp-any.mjs <expr>` + `CDP_MATCH` | 直连某个平台页面（目标窗口）执行 DOM 脚本 |
| `cdp-try-urls.mjs <match> <out> <url...>` | 批量试探 URL 并打印最终 href/title/文本 |
| `cdp-shot.mjs` | 对目标窗口截图 |
| `expr-xhs-image.mjs` / `expr-dy-image.mjs` | 图文发布真机用例 |
| `expr-stats-all.mjs` / `expr-status-all.mjs` | 取数 / 登录态真机用例 |

真机迭代节奏（1 分钟一轮）：改代码 → `cd packages/desktop && electron-vite build` →
kill 客户端进程 → `node _probe/patch-asar.cjs` → 带 `--remote-debugging-port=9222` 重启 → 跑 `cdp.mjs`。
注意：重启后第一次发布常报「打开页面失败：页面没有响应」（冷启动），直接重跑一次。
