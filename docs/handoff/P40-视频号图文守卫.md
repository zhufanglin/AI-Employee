# P40：视频号图文（type=image）真机结论与前置守卫

## 一、真机实测结论
用户要求「视频号图文也要能发」。2026-11-10 11:06Z 真机执行 `window.fcm.platform.publish({ platform:'shipinhao', type:'image', mediaPaths:['_demo\image-gen.jpg'], title, content })`：
- 点「图文」tab 的点击没有落在真 tab 上，页面仍是视频发布表单（有「视频标注」「声明原创」）；
- 上传控件仍是 `accept=video/mp4` 的视频上传器，图片塞不进去；
- `发表` 按钮始终 disabled，10 步跑完报「发布结果未确认」，截图：
  `…\platform-logs\shipinhao-2026-11-10T11-06-38-945Z---failed.png`。

⇒ **视频号网页版没有独立的图文上传控件**，当前版本无法从网页端发图文。

## 二、做法：声明不支持 + 前置守卫（不造假成功）
1. `packages/desktop/src/main/platform-drivers.ts` `PLATFORMS` 里 shipinhao 改 `types: ['video']`（带注释说明真机结论）。
2. `packages/desktop/src/main/platform.ts` `doPublish` 开头新增守卫：
   `const wantType = input.type === 'image' ? 'image' : 'video'; if (!platformSupports(platform, wantType)) throw new Error(driver.name + ' 暂不支持发布' + …)`
   —— 立即失败，不再白跑 2 分钟。真机返回：
   `{ ok:false, message:'发布失败：视频号 暂不支持发布图文（图片）：视频号网页版的图文上传控件还没适配，请改用视频发布，或直接在手机端发图文', steps:0 }`
3. `packages/desktop/src/renderer/src/pages/PlatformPublish.tsx`：`PLATFORMS` 加 `supportsImage`（视频号 false，tip「视频号助手 · 仅视频（图文未适配）」）；publish() 里按类型过滤 `usable` 并提示「已跳过不支持图文的平台：…」；全被过滤时报「所选平台不支持发布图文：视频号网页版只能发视频（请在手机端发图文，或改成视频发布）」。
