# T-31 桌面端文生图 / 图生视频（验收记录）

> codex 实现（`MediaCreation.tsx` + 10 条 `media:*` IPC + Shell 两个 tab），因审批策略无法启动桌面客户端而 `blocked(env)`；dsh-lead 接手补 GUI 验收。

## 实现清单
- 页面：`packages/desktop/src/renderer/src/pages/MediaCreation.tsx`（84 行，`mode: 'image' | 'video'` 双模）
- 导航：`packages/desktop/src/renderer/src/pages/Shell.tsx` 新增「🖼️ 文生图」「🎞️ 图生视频」两个 tab

- 轮询：任务处于 `QUEUED|RUNNING` 时每 8 秒查一次 `GET /api/media/tasks/:taskId`，切页面不丢（组件保持挂载）

## 踩坑（很重要，会影响以后的桌面冒烟）
1. **`--user-data-dir` 的旧 profile 会带上 `settings.apiBase=127.0.0.1`**：直接跑会打到本地服务端，测试账号没积分 → 返回 402「算力不足，请充值」。要么用干净 profile + `FCM_API_BASE`，要么先在设置页改服务端地址。
2. **生产短信 60 秒频控**：连续冒烟会 `验证码发送过于频繁` → 登录失败 → 停留在登录页（表现为 `no-nav`）。脚本间隔要 ≥ 70 秒。
3. **隐藏面板仍在 DOM 里**：`Shell.tsx` 用 `<div hidden>` 挂两个 `MediaCreation`，冒烟脚本 `document.querySelector('button')` 会命中隐藏的「文生图」提交按钮（我第一版就误触发了一次 image_gen 扣 20 积分）。脚本要按可见性过滤（`offsetParent !== null`）。
4. **本机到 OSS / 域名偶发 TLS reset 与 connect timeout**（`ECONNRESET`、`UND_ERR_CONNECT_TIMEOUT`）：截图里曾出现图片未加载的破图，重试即正常，不是产品 bug。

## 顺手发现的产品问题（未改，留给后续）
- 生成结果的 OSS 对象是**公开读**（知道 URL 即可下载）。若要保护客户素材，应改为私有读 + 后端签发短期 URL。
- 页面缺「取消 / 重新生成」：任务提交后只能等 3–4 分钟。
